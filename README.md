# Showcase Project: Codex Collective

Codex Collective is an intereactive book tracking web application that allows users to track their reading journey, discover new books, and interact with friends!

## This web application consists of the following pages:

- **Login Page:**
  - Page with a simple form to allow users to log in. As this project is based on local storage, users only need to type in a username of their choice
- **Home Page/Dashboard:**
  - The "Home" page consists of a progress bar, recently added, and recommended title sections. The progress bar allows users to track their reading goals for the year
- **My Books Page:**
  - The "My Books" page gives users a more detailed view of their book collections. These collections are broken down into "Want to Read", "Currently Reading", and "Read" sections
- **Book Details Page:**
  - When a user clicks on a book, users will see the "Details" page which includes the book title, author, description, along with other additional details. Users are also able to manage their reading status for the book selected, which will move the book to the corresponding collection
- **Browse Page:**
  - The "Browse" page allows users to search for specific titles and add them to your "Want to Read" collection
- **Community Page:**
  - Users can socialize and interact with one another on the "Community" page. Users are able to like and comment on each other's reading activities. Here useres will see what others are reading and what they add to their lists.

## Technologies Used:

- Vite
- React & React Router
- TypeScript
- CSS
- Tailwind CSS Framework
- Google Books API
- Zustand
